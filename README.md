# readingclub

Разборы статей: из сториборда собираются **и слайды, и видеоролик** — из
одного и того же кода на Manim.

```
deckkit/              переиспользуемый каркас — общий для всех разборов
setup/                системное окружение (шрифты, зависимости)
paper_1_minimalism/   разбор №1: Deep Hash Embeddings
```

Каждый разбор — самостоятельная папка с манифестом `deck.json`; `deckkit`
ничего не знает о конкретной статье, кроме того, что написано в манифесте.

## Как собрать разбор

```bash
python3 -m venv .venv
.venv/bin/pip install manim python-pptx fonttools
sudo apt-get install -y ffmpeg libcairo2-dev libpango1.0-dev \
                        fonts-inter fonts-jetbrains-mono
sudo cp setup/fonts-local.conf /etc/fonts/local.conf && fc-cache -f

.venv/bin/python -m deckkit.storyboard  paper_1_minimalism   # .dc.html → frames.json
.venv/bin/python -m deckkit.build_video paper_1_minimalism   # 1920×1080 @ 60 → out/
.venv/bin/python -m deckkit.build_pptx  paper_1_minimalism   # слайды из тех же секций
.venv/bin/python -m deckkit.verify      paper_1_minimalism   # критерии приёмки
```

`--quality l` на сборщиках даёт быстрый черновой прогон в 480p15.
`deckkit.digest <разбор> <кадр>` печатает кадр сториборда как компактный
чертёж — читать HTML руками не нужно.

## Как устроен каркас

**Кадр = секция.** Часть разбора — одна непрерывная сцена Manim, разрезанная
на кадры через `self.frame("5.6")` (обёртка над `next_section`). Из одного
рендера получается и ролик, и последний кадр каждой секции для слайда.

**Хронометраж — из сториборда.** `settle()` доводит кадр ровно до
длительности, объявленной в `data-speaker-notes`. Остаток бюджета он не
замораживает, а проигрывает *биты* — короткие анимации Manim по элементам,
которые несут смысл кадра (`b_indicate`, `b_wave`, `b_flash_along`, `b_box`,
`b_spark`, `b_ripple`). Последние 0.9 с всегда неподвижны, чтобы слайд брался
с чистого финального состояния. Бюджет считается по часам рендерера, а не по
сумме запрошенных `run_time`: часть анимаций Manim пересчитывает свою
длительность после конструирования.

**Координаты как в макете.** Холст 1920×1080, `135 px = 1 юнит`, шаг сетки
45 px = ⅓ юнита, поля 135 px. `px()` и `pos()` переводят пиксели макета в
юниты Manim.

**Текст.** `fs(css_px)` пересчитывает CSS-кегль в `font_size` Manim через
измеренную константу. Pango набирает текст в размере `font_size / 4.8`, то
есть подпись 28 px верстается кеглем около 3 pt и увеличивается в двадцать
раз — на таком кегле хинтинг округляет ширину каждого глифа до целого
пикселя, и интервалы получаются рваными. `components.text()` набирает в
`SHAPE_SCALE = 16` раз крупнее и уменьшает мобжект обратно; на то же число
увеличивается ширина раскладки Pango, иначе длинные подписи начали бы
переноситься. Текст ставится по базовой линии, поэтому подпись стоит в одной
точке на всех кадрах независимо от того, какие в ней буквы.

**Шрифты.** Inter и JetBrains Mono не покрывают весь юникод, который
встречается в формулах: в моно нет `ᵢ`, `⁻`, `ˣ`, `⟹`, в Inter — `ᵀ`, `ℝ`,
`↦`, `∈`, `⌊`, `⌋`. `setup/fonts-local.conf` выстраивает цепочку подстановки
на DejaVu Sans и отбрасывает растровые unifont/ipag, иначе Pango подставил бы
именно их.

## Новый разбор

```
paper_N_name/
  deck.json          манифест: части, сцены, какие кадры пропустить
  storyboard/        исходный .dc.html из Claude Design
  deck/              part1.py … partN.py — по модулю на часть
  build/             frames.json и промежуточный media/ (в git не идёт)
  out/               ролик, части, PPTX
```

`deck.json`:

```json
{
  "name": "dhe",
  "storyboard": "storyboard/….dc.html",
  "parts": [1, 2, 3],
  "scene": "Part{n}",
  "module": "deck/part{n}.py",
  "skip": ["S1", "S2", "S3"]
}
```

`skip` — кадры, которые есть в сториборде, но в разбор не входят
(спецификация системы, служебные карты).
